# Health AI Assistant: Symptom Predictor & Medical Chatbot

## Project Overview
A full-stack healthcare application that provides intelligent symptom analysis and real-time medical consultation.

## Features
### 🔍 Symptom Predictor
- AI-powered disease diagnosis using Groq AI
- Sorted output based on possibility (Higher to lower)
- Confidence percentages and severity levels
- Treatment recommendations and risk factors
- Interactive disease information cards

### 💬 Health Chatbot
- Real-time medical Q&A
- Contextual health advice

### 🎨 User Interface
- Responsive split-screen design
- Medical-themed color scheme
- Hover effects and animations
- Real-time updates

## Technologies Used
### Frontend
- React.js with Hooks
- JavaScript ES6+
- CSS3 with animations
- Responsive Web Design

### Backend
- Spring Boot Framework
- Java
- RESTful APIs
- CORS Configuration

### AI Integration
- Groq AI API
- Natural Language Processing
- Prompt Engineering
- JSON Response Handling

## Benefits
- 🩺 Preliminary medical guidance
- 🧠 AI-powered symptom analysis
- 📱 Responsive and user-friendly interface
- ⚡ Real-time consultation
- 🎯 Educational health information
